# Formal Pixel Art asset root

The Registry points to the category folders below. Add reviewed PNG/WebP
files here and set the matching Registry entry to `enabled: true` after visual
QA. Empty category markers intentionally contain no fake placeholder art.

The formal Player Jelly sheet is intentionally present but remains
`enabled: false` until Phase 1.5B-2 runtime integration. Its manifest and
strict acceptance command live beside the sheet under
`characters/player/`.
